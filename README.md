# 🧵 GenZ Thread Creator 🧵

Ứng dụng web tạo thread kiểu GenZ tự động sử dụng Gemini API.

## Demo
Truy cập ứng dụng tại: [https://nahvine.github.io/Generate_Paragraph_Threads/](https://nahvine.github.io/Generate_Paragraph_Threads/)

## Tính năng

- Tạo thread ngẫu nhiên với nhiều mood khác nhau (angry, cute, sad, casual)
- Giao diện hiện đại, thân thiện với người dùng
- Nút copy nhanh chóng
- Hiệu ứng loading và thông báo lỗi

## Cài đặt

1. Clone repository:
```bash
git clone https://github.com/Nahvine/Generate_Paragraph_Threads.git
cd Generate_Paragraph_Threads
```

2. Cài đặt dependencies:
```bash
pip install -r requirements.txt
```

3. Tạo file `.env` và thêm API key của bạn:
```
GEMINI_API_KEY=your_api_key_here
```

4. Chạy ứng dụng:
```bash
python app.py
```

5. Truy cập ứng dụng tại `http://localhost:5000`

## Sử dụng

1. Nhấn nút "Tạo Thread Mới" để tạo một thread ngẫu nhiên
2. Đợi trong giây lát để thread được tạo
3. Nhấn nút "Copy" để sao chép nội dung thread

## Công nghệ sử dụng

- Backend: Flask
- Frontend: HTML, CSS, JavaScript
- API: Gemini API
- Font: Inter
